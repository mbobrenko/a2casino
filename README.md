# A2Casino — первая версия (MVP)

Онлайн-казино: Go API + сайт игрока + бэк-офис. Все платежи и игры здесь **имитированы**
(тестовый платёжный шлюз, симулятор крипто-процессинга, тестовый игровой провайдер).

| Что | Адрес | Вход |
| --- | --- | --- |
| Сайт игрока | http://localhost:3000 | регистрация на сайте (страна, например, Чили) |
| Бэк-офис | http://localhost:3001 | `admin@a2casino.local` / `admin12345` |
| API | http://localhost:8080 | описание в `docs/API.md` |

## Запуск на Windows

1. Установить **Docker Desktop** (https://docs.docker.com/desktop/setup/install/windows-install/) с включённым WSL 2.
   На компьютере с ARM-процессором (Snapdragon и т. п.) нужна версия **Windows – Arm**, обычная x64 не запустится.
   Все образы проекта собираются и под x64, и под ARM64 без изменений. После установки
   перезагрузить компьютер и один раз открыть Docker Desktop.
2. В PowerShell:
   ```powershell
   cd C:\Users\mbobr\A2Casino\a2casino
   docker compose up --build
   ```
   Первая сборка занимает несколько минут. Остановить: `Ctrl+C`, данные базы сохраняются.
   Начать с чистой базы: `docker compose down -v`.

## Что попробовать

1. Зарегистрироваться на сайте (страна Чили или Мексика; Бразилия и США заблокированы, возраст 18+).
2. **Кошелёк → Пополнить**: банковская карта открывает тестовую страницу оплаты, кнопка Pay зачисляет деньги.
   USDT/BTC показывают адрес; кнопка «Симулировать перевод» имитирует входящую транзакцию,
   «Рисковый перевод» — транзакцию, которую AML-проверка замораживает.
3. **Лобби**: слоты от тестового провайдера (ставки идут через seamless-wallet колбэки) и своя игра
   **Dice** с доказуемой честностью.
4. **Вывод** требует пройденной верификации: в бэк-офисе откройте карточку игрока, поставьте
   «Верификация → verified» (с комментарием), затем закажите вывод и одобрите его в «Выводах».
5. В карточке игрока видны баланс, InOut, ставки и выигрыши, лог ставок, платежи, леджер и журнал действий.

```
backoffice/  бэк-офис (Next.js)

```

## Сервер с живой ссылкой

**Бесплатно на Render:** `render.yaml` в корне. В Render: New → Blueprint → репозиторий `a2casino` → Apply
(попросит пароль админа). Сервисы засыпают через 15 минут без трафика, бесплатная база живёт 30 дней.

**Свой сервер:** См. [deploy/README.md](deploy/README.md): Hetzner Cloud, HTTPS и автообновление из GitHub.

## Разработка без Docker

Нужны Go 1.26+, Node 22+, PostgreSQL 16.

```bash
cd backend && DATABASE_URL=postgres://postgres:postgres@localhost:5432/casino?sslmode=disable go run ./cmd/api
cd web && npm install && npm run dev          # :3000
cd backoffice && npm install && npm run dev   # :3001
# тесты (нужна отдельная пустая база casino_test):
cd backend && TEST_DATABASE_URL=postgres://postgres:postgres@localhost:5432/casino_test?sslmode=disable go test ./...
```

Нагрузочный тест: запустить API с `AUTH_RATE_LIMIT=0`, затем `k6 run -e RPS=1000 loadtest/wallet.js`.

## Что сделано и чего пока нет

Сделано: регистрация с гео-блоком и проверкой 18+, кошелёк с двойной записью и идемпотентностью,
seamless-wallet API для провайдеров (bet/win/rollback, подпись HMAC), Dice с provably fair,
фиатные и крипто-депозиты (с подтверждениями и AML-заморозкой), выводы с резервом и одобрением,
бэк-офис с ролями и журналом действий.

Пока нет: Kafka и Redis, бонусный движок и вейджер, лояльность и VIP, турниры, CRM-цепочки,
партнёрка, сегментация, двойное одобрение выводов (four-eyes), реальные провайдеры и платёжки.

Перед продом обязательно сменить `JWT_SECRET`, все `*_SECRET`, пароль админа и выключить `DEV_TOOLS`.
